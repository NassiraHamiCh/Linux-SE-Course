# 🟢 Niveau 1 : Débutant

## Ex 1 : Arborescence
Créer `projet/{src,docs,tests,data}`  
**Commandes:** `mkdir -p`

## Ex 2 : Recherche
Lister tous les `.txt` dans `fichiers.log`  
**Commandes:** `find`, `>`, `wc -l`

Copier scripts dans `backup_2025-02-06`  
**Commandes:** `date +%Y-%m-%d`, `mkdir`, `cp`

Générer `rapport.txt` (date, user, nb fichiers, disque)  
**Commandes:** `echo`, `>>`, `df -h`
