# 🎯 Scripts Linux Progressifs

## 📚 Structure

5 niveaux de difficulté croissante avec **20 exercices** au total :

- **Niveau 1** 🟢 Débutant (4 exercices)
- **Niveau 2** 🟡 Intermédiaire (4 exercices)  
- **Niveau 3** 🟠 Avancé (4 exercices)
- **Niveau 4** 🔴 Expert (4 exercices)
- **Niveau 5** ⚫ Maître (4 exercices)

## 🚀 Utilisation

```bash
# Rendre les scripts exécutables
chmod +x niveau*/solutions/*.sh

# Exécuter un script
./niveau1/solutions/ex1_arborescence.sh
```

## 📖 Concepts par niveau

**Niveau 1:** `mkdir`, `find`, `cp`, `date`, `>`, `>>`  
**Niveau 2:** `grep`, `pipes |`, `2>`, `tar`, `ps`  
**Niveau 3:** `awk`, `sed`, `regex`, fonctions, `case`  
**Niveau 4:** Boucles avancées, `xargs`, `trap`, parallélisation  
**Niveau 5:** Scripts professionnels, optimisation, sécurité

Bon apprentissage ! 🚀
