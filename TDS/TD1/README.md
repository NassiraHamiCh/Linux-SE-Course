## 📋 Objectifs

- Maîtriser les commandes essentielles de navigation et manipulation de fichiers
- Comprendre la structure du système de fichiers Linux
- Apprendre à afficher des informations système

---

## 📝 Exercice 1 : Questions de cours

1. **Citez les principales caractéristiques du système d'exploitation Linux.**

2. **Donnez le rôle du noyau de Linux.**

3. **Donnez le rôle du shell.**

4. **Quelle est la différence entre la virtualisation basée sur l'hôte et la virtualisation basée sur le matériel (bare-metal) ?**

---

## 📝 Exercice 2 : Informations système

En utilisant les différentes commandes possibles en ligne de commande, répondez aux questions suivantes.

1. Afficher des informations détaillées sur la distribution Linux installée.

2. Afficher le nom de la machine.

3. Afficher le nom d'utilisateur actuel.

4. Afficher la liste des utilisateurs actuellement connectés.

---

## 📝 Exercice 3 : Navigation et manipulation de répertoires

En utilisant les différentes commandes possibles en ligne de commande, répondez aux questions suivantes.

1. Vérifiez si vous êtes dans votre répertoire de connexion.

2. Dans votre répertoire de connexion, créez l'arborescence **`IIA3/SEI`**.

3. Dans votre bureau, créez répertoire **`Compte-rendu1`**.

4. Déplacez **`Compte-rendu1`** vers **`SEI`**.

5. Affichez les répertoires sous forme d'arborescence.

6. Supprimez le répertoire **`IIA`**.

---

## 📝 Exercice 4 : Manipulation de fichiers

En utilisant les différentes commandes possibles en ligne de commande, répondez aux questions suivantes.

1. Dans votre répertoire de connexion, créez les répertoires **`TDM1`** et **`TDM1_SEI`**.

2. Créez le fichier **`TDM1.txt`**.

3. Dupliquez le fichier **`TDM1.txt`** sous le nom **`TDM1_SEI.txt`**.

4. Déplacez le fichier **`TDM1_SEI.txt`** dans le répertoire **`TDM1_SEI`**.

5. Affichez le contenu du répertoire **`TDM1_SEI`** en détail.

6. Supprimez le fichier **`TDM1.txt`** en demandant une confirmation avant la suppression.

---

## 💡 Conseils

- Utilisez `man` pour obtenir de l'aide sur les commandes : `man ls`
- Utilisez la touche `Tab` pour l'auto-complétion
- Utilisez les flèches `↑` et `↓` pour naviguer dans l'historique des commandes
- La commande `pwd` affiche votre répertoire courant
- `~` représente votre répertoire personnel
